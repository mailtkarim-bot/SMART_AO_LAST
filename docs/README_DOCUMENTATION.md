# Documentation SMART AO

La documentation est rangée dans deux ensembles : **`Actifs/`** pour les autorités et le travail courant, **`Archive/`** pour les cahiers remplacés, audits datés, propositions et anciennes revues. Aucun contenu n’a été supprimé.

## Pour comprendre ce qu’il faut construire

Commencer par l’[index actif](Actifs/00_INDEX_DOCUMENTATION_ACTIVE.md), puis les trois cahiers complets réunis dans `Actifs/01_Cahiers_des_charges/` :

1. [Product Freeze métier v3.1](Actifs/01_Cahiers_des_charges/SMART_AO_Cahier_Directeur_Produit_Metier_OWNER_FREEZE_v3.1.md) — autorité produit/métier.
2. [Cahier directeur métier v3.1](Actifs/01_Cahiers_des_charges/SMART_AO_CAHIER_DIRECTEUR_METIER_MASTER_v3.1.md) — périmètre métier complet.
3. [Cahier technique d’exécution v3.1](Actifs/01_Cahiers_des_charges/SMART_AO_CAHIER_TECHNIQUE_EXECUTION_v3.1.md) — traduction technique et critères de preuve.

## Pour reprendre le travail

Lire ensuite le [plan global](Actifs/00_Pilotage_et_audits/SMART_AO_PLAN_GLOBAL_CONCEPTION_REALISATION_CHECKLIST_v0.1.md), qui seul indique la tranche active, puis les décisions et audits cités par ce plan. Les parcours, preuves, architecture et qualifications locales sont classés dans leurs dossiers actifs dédiés.

`Archive/` conserve les versions remplacées et les sources de conception. Les audits T0 et les propositions V3.0 restent disponibles dans `Archive/`, comme provenance sans autorité active. Les livrables actifs restent sous `docs/`, jamais sous `rapports/`. **NO-GO public maintenu.**
