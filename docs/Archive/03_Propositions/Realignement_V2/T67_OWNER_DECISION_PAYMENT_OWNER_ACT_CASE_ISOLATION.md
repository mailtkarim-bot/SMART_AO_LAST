# T67 — Décision propriétaire de l’isolation inter-Affaires

**Statut :** approuvé localement — NO-GO public maintenu

Le Patron approuve l’isolation inter-Affaires :

- les identifiants de rejeu restent liés à une seule Affaire ;
- un changement de `case_id` crée une nouvelle intention ;
- aucune preuve ou donnée d’une autre Affaire n’est réutilisée ou affichée ;
- les contrôles tenant et serveur restent obligatoires ;
- aucun paiement ni effet juridique n’est déduit ;
- le NO-GO public est maintenu.

Cette décision valide la séparation des intentions C07. Elle ne remplace pas
les contrôles d’autorisation backend et ne constitue pas une preuve de paiement.
