# T46 — Préparation du prochain cycle métier local

**Statut :** prêt à cadrer — NO-GO public maintenu

## Objet

Définir le prochain cycle métier après clôture du cycle des inconnus, sans
réutiliser implicitement ses décisions et sans ouvrir de pilote public.

## Règles

- repartir des autorités produit/métier v2 actives ;
- sélectionner une seule capacité métier suivante ;
- conserver les preuves T34–T45 comme historique ;
- expliciter les décisions propriétaires attendues ;
- maintenir les gates locales et le NO-GO public.
