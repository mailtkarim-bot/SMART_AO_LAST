# T0 — Carte de couverture du Deep Core dans le code

**Périmètre :** code commité au HEAD `1c8ac62` ; les modifications locales non commitées sont signalées séparément et ne sont pas assimilées à la version publiée.  
**Verdict :** le Deep Core n’est pas absent ; il est partiellement matérialisé en plusieurs bounded contexts. Il n’existe pas encore de chaîne complète ContractBaseline/version signée → applicability → impact structuré → P3 → contrat vendu → OS/événement → droit/action/échéance → preuve → settlement/DGD → REX.

## Ownership recommandé (proposition)

Garder `Engagement Control` comme **modèle logique transversal**. Pour la première verticale, conserver l’écriture existante de preuve baseline dans DCE, le contrat instrumenté/supersession/evidence dans Pricing, la décision P3 dans Decision et la passation dans PatronAction/Submission; ajouter uniquement les relations ou projection manquantes qui sont prouvées par la tranche. N’envisager un MOVE du cycle Payment qu’après une cartographie des consumers, routes, migrations, transactions et tests.
